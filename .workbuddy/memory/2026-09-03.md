## Qwen Rerank → Jina 格式转换网关（Go 微服务）

- 新建 Go 项目 `api_embedding_rerank`，实现百炼 text-rerank 到 Jina rerank 的协议转换，供 new-api 接入。
- 关键设计：
  - 对外 `POST /v1/rerank`（Jina 格式：query/documents/top_n/return_documents），对内转百炼（input.query/input.documents/parameters.top_n）。
  - **base_url 复用**：上游 WorkspaceId 前缀通过请求头 `X-Base-Url` 传入（`X-Upstream-Key` 可覆盖 key），单实例服务多 Workspace。
  - 高并发：单例 http.Client（MaxIdleConnsPerHost=并发上限）+ 信号量限流（MAX_CONCURRENCY）+ sync.Pool 缓冲复用 + 超时分层 + 10MB 请求体限制 + 禁自动重定向。
- 文件：cmd/server/main.go、cmd/mockupstream/main.go、internal/rerank/rerank.go、rerank_test.go。
- 验证：`go vet` + `go test`（3 用例）+ 编译通过；用 mock 上游端到端测试确认双向转换正确。
- 后续补充（同日）：
  - 新增 `instruction` 透传：请求头 `X-Instruct` 优先，或请求体 `instruction` 字段，映射到百炼 `parameters.instruction`。
  - 边界健壮性：`top_n` 超文档数自动截断为文档数；`top_n=0`/`<0` 视为未指定（不传）。
  - 新增 Dockerfile（多阶段构建，alpine 运行）与 .gitignore。
  - 端到端复测通过：mock 日志确认 `instruction` 与 `top_n` 截断正确传到上游。
